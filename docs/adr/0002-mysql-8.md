# 0002. 데이터베이스: MySQL 8, 컨텍스트별 스키마

- 상태: 확정
- 날짜: 2026-11-03

## 맥락

글 수가 수백 건 수준인 개인 블로그다. 한글 검색이 필요하고, 나중에 컨텍스트를 분리할 여지를 남기고 싶다.

## 결정

MySQL 8(로컬은 8.4 LTS 이미지)을 쓰고, 컨텍스트마다 스키마를 하나씩 둔다(`blog_article`, `blog_comment`, `blog_auth`, `blog_media`). 스키마를 넘는 FK는 만들지 않는다. 한글 검색은 FULLTEXT ngram 파서로 처리한다.

## 결과

- 검색 엔진 없이 MVP 검색을 처리한다. 관련도 정렬이 필요해지면 Elasticsearch를 검토한다.
- 다른 컨텍스트의 ID는 값으로만 저장하므로, DB를 물리적으로 나눠도 스키마를 고치지 않아도 된다.
