# 0003. 레포 구성: 백엔드와 프론트엔드를 별도 git 레포로

- 상태: 확정
- 날짜: 2026-11-03

## 맥락

백엔드(VM, Docker Compose)와 프론트엔드(Vercel)는 배포 대상과 수명주기가 다르다.

## 결정

작업 폴더 아래에 `backend/`와 `frontend/`를 나란히 두고, 각각 별도 git 레포로 관리한다. API 스펙은 이 레포의 `docs/api/openapi.yaml`이 정본이고, 프론트 레포는 사본을 `pnpm sync:api`로 가져가 타입을 생성한다.

## 결과

- CI와 이력을 레포별로 관리한다.
- API를 바꾸면 백엔드를 먼저 배포하므로, API 변경은 하위 호환으로 내야 한다.
