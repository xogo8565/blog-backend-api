# 0001. 언어와 프레임워크: Java 21 + Spring Boot

- 상태: 확정
- 날짜: 2026-11-03

## 맥락

1인 개발로 백엔드를 만든다. 설계와 아키텍처 연습에 집중하려면 언어를 새로 익히는 부담이 작아야 한다.

## 결정

Java 21과 Spring Boot(착수 시점 최신 안정판, 4.1.2)를 쓴다. VO와 DTO는 record로, 상태는 sealed interface와 패턴 매칭으로 표현한다.

## 결과

- 가장 익숙한 언어라 설계 판단에 시간을 더 쓸 수 있다.
- Kotlin의 null 안전성은 없으므로, 없을 수 있는 조회 결과는 Optional로 돌려주는 규칙을 둔다.
